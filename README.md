## 目录结构

```text
.
├── README.md
├── assets/                  # 封面
└── days/                    # 所有题目按天收在这
    └── M01--D01/            # 第 1 个月第 1 天
        ├── wp.md      # 当日 Writeup（人话版）
        ├── 题目说明.md      # 原题说明（如有）
        ├── 1  # 题目样本
        └── images/          # 截图，全是证据
```

## 约定

- 每天一个目录：`days/M{月}--D{日}`，如 `days/M01--D01`、`days/M02--D15`
- Writeup 叫 `wp.md`，每天目录里一份
- 图放当日 `images/`，正文只用相对路径——别再把 `C:\Users\...` 传上来，丢人
- 题目样本跟着一起提交，别人才复现得了；来路不明的样本不进仓库
- 样本仅限公开 crackme / CTF 题目 / 自己的程序，纯粹学习分析

## 环境

- 静态：IDA Pro / Ghidra
- 动态：x64dbg / GDB + pwndbg
- 跑题：WSL / Kali Linux
- 脚本：Python 3
