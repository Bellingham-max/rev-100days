## 约定

- 每天一个目录：`M{月}--D{日}`，如 `M01--D01`、`M02--D15`
- Writeup 命名为 `题目{四位序号}.md`，序号与天数对应
- 图片统一放在当日 `images/` 目录下，正文只使用相对路径（Typora 用户注意不要保留本机绝对路径）
- 题目样本随 Writeup 一起提交，方便他人复现；不收录任何来源不明或不方便公开的样本
- 所有样本均为公开 crackme / CTF 题目 / 自有程序，分析仅用于学习

## 环境与工具

- 静态分析：IDA Pro / Ghidra
- 动态调试：x64dbg / GDB + pwndbg
- 运行环境：WSL / Kali Linux
- 脚本：Python 3
